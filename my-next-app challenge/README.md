
# Portal Auto

### Plataforma de serviços automotivos | Projeto acadêmico FIAP

Projeto desenvolvido originalmente em 2024, durante um desafio acadêmico da FIAP em parceria com a Porto Seguro.

O objetivo foi explorar o desenvolvimento de uma plataforma digital para serviços automotivos, reunindo informações, formulários e funcionalidades interativas em um único ambiente.

Em 2026, o projeto passou por um redesign, com foco na modernização da interface, experiência do usuário, responsividade e organização do código.

> **Aviso:** Este é um projeto acadêmico independente. Não é um site oficial da Porto Seguro e não realiza operações comerciais ou atendimentos reais.

## Funcionalidades

- **Consulta de CEP:** integração real com a API ViaCEP, retornando rua, bairro, cidade e UF.
- **Agendamento:** simulação de visita à oficina, com validação de formulário e resumo das informações.
- **Revisão automotiva:** apresentação interativa de seis sistemas do veículo.
- **Problemas no veículo:** orientações educativas organizadas por categorias.
- **Planos:** exploração interativa de perfis para carro, moto e caminhão.
- **FAQ:** perguntas expansíveis com busca e filtros.
- **Login e cadastro:** fluxos demonstrativos com validação de campos, sem autenticação real.

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- CSS Modules
- API ViaCEP
- React Icons

## Evolução do projeto

**2024 — Desenvolvimento acadêmico**

Criação do protótipo inicial no contexto do desafio FIAP e Porto Seguro, com páginas de serviços automotivos e integração com a API ViaCEP.

**2026 — Redesign e melhorias**

Reestruturação visual das páginas, padronização dos componentes, modernização dos formulários, melhorias de navegação e implementação de novas interações demonstrativas.

## Como executar localmente

Instale o Node.js e execute os comandos dentro da pasta `my-next-app`:

    npm install
    npm run dev

Depois, acesse:

http://localhost:3000

O Portal Auto representa uma experiência de aprendizado em desenvolvimento web, desde a implementação inicial até sua evolução visual e funcional.

Esta versão foi preparada para fins de estudo, demonstração técnica e portfólio.
